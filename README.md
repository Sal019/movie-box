# MovieBox — iQONE-theme UI/UX Demo (Flutter)

A Flutter recreation of the iQONE video-blog theme's look and flow:
dark #111319 surfaces with the signature green (#1CC749) accent.

- **Home** — hero slider, Popular Posts, Top 10 rank rail, Top Picks, Originals, label cloud, site footer
- **Detail** — poster + meta, popularity rank, green Play button, Watch Later / Favorite (local), Deskripsi with Show all/less, share row, episode grid, recommendations
- **Play** — video player (green progress), Server 1/2 picker, season + episode selector, recommendations
- Plus Search, label pages, History and Favorites (stored locally)

Runs as a website and as an Android app from one codebase. Demo content is fictional; sample videos are open Blender films.
